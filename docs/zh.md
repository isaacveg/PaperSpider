# PaperSpider 使用说明

[项目首页](../README.zh.md) · [English guide](en.md)

PaperSpider 用来把完整的会议论文列表逐步缩小为需要关注的论文集合，并完成查看、下载和导出。

## 启动应用

安装 Python 3.10+ 和 [uv](https://docs.astral.sh/uv/)，克隆仓库后运行：

```bash
uv run paperspider
```

## 1. 选择会议

1. 左侧边栏会列出本地数据集，点击即可打开论文列表。
2. 如需新增数据集，点击 **会议数据集** 旁的 **+**。
3. 选择基础目录、会议和年份，然后点击 **抓取数据集**。

论文列表会保存在本地，下次可以直接打开。需要同步最新列表时，点击选中数据集右侧的刷新按钮。

选中数据集后，点击条目右侧的 **⋯** 可以 **在文件夹中打开** 或 **删除数据集**。删除会把数据集文件夹移动到 `.trash`，之后需要重新抓取。拖动侧栏边缘可以调整宽度，也可以点击收起按钮隐藏侧栏。

## 2. 使用筛选

点击论文列表上方的 **筛选**，在弹窗中添加规则：

- **包含**：论文必须符合该条件。
- **偏好**：默认是偏好条件；设置 **偏好条件最低匹配数** 后，至少要符合指定数量的偏好条件。
- **排除**：符合该条件的论文会被排除。

生效的规则会以 chips 形式显示在搜索框下方。点击 chip 上的关闭按钮即可移除该规则，无需重新打开弹窗。

## 3. 进一步筛选

在论文列表上方的 **在结果中搜索** 中输入关键词。它只搜索当前筛选结果，不会改动筛选规则。

## 4. 查看与下载

点击论文行后，右侧详情区会显示标题、作者、标签、摘要和本地文件。

- 使用 **打开 PDF** 或 **复制 BibTeX** 操作当前论文。BibTeX 缺失时会自动抓取并复制到剪贴板。
- 在 **本地文件** 下点击 **在文件夹中显示**，可直接打开文件管理器并定位到已下载的 PDF。
- 勾选多篇论文后，使用底部操作栏的 **下载摘要** 或 **下载 PDF**。
- 使用表头复选框全选或清空当前可见论文，使用 **反选** 反转当前选择。
- 使用底部的 **任务日志** 查看进度或取消正在运行的任务。

## 5. 导出结果

勾选需要的论文，点击 **导出**，可将标题、作者和可选摘要导出为 CSV、JSON 或纯标题列表。BibTeX 请在右侧详情中使用 **复制 BibTeX**。

## 本地数据

PaperSpider 按以下结构保存数据：

```text
<基础目录>/<会议>/<年份>/
  papers.sqlite
  pdf/
  bib/
  exports/
```

在 **Settings** 中可以调整请求间隔和界面外观。**Theme** 可选择跟随系统外观，
或固定为 Light / Dark。界面语言跟随系统语言（中文或英文）。批量下载时建议保留
适当的请求间隔。

## 命令行

如需脚本化访问同一份论文库，使用 `uv run paperspider-cli`。完整手册见
[man/paperspider-cli.1](../man/paperspider-cli.1)：

```bash
man ./man/paperspider-cli.1
```
